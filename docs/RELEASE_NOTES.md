**從系統分享選單直接更新無電池 NFC 電子紙——自動辨識尺寸、精準色彩抖動、100% 本機離線處理。**  
*Update battery-free NFC E-Paper displays directly from Android's share sheet—100% offline.*

## 下載與安裝 (Download)

請在 Android 手機上直接下載安裝包（`.apk`），開啟檔案即可完成安裝：

### [下載 Android 安裝包 (`tapink-release.apk`, 840 KB)](https://github.com/dabendan2/tapink/releases/download/v2.4.0/tapink-release.apk)
*支援具備 NFC 功能的 Android 7.0 至 Android 15+ 裝置*

> **隱私與安全說明**  
> TapInk **不申請網路連線權限**（僅具備單一 `android.permission.NFC` 權限，可隨時於系統「應用程式資訊 ➔ 權限」中確認）。所有照片、名片與條碼皆在手機本機端處理並直接傳送至電子紙，不會上傳至雲端，亦無廣告或背景常駐程序。

## 快速上手

1. **選擇畫面**：在 Google 相簿、Canva 或任何設計 App 中準備好照片、名片或桌牌畫面。
2. **點選分享**：在系統分享選單點選 **「刷入電子紙 (TapInk)」**（或直接開啟桌面上的 `TapInk 電子紙` 選取圖片），螢幕底部將滑出感應面板。
3. **貼靠更新**：將**手機背面 NFC 感應區**平貼於電子紙中央並保持穩定。待進度達 100% 且畫面刷新完成後，面板將自動關閉。
   - *展示模式：若手邊暫無實體電子紙，可開啟 TapInk 主畫面並**長按中央預覽卡片 1 秒**，啟動內建展示模式（Demo Mode）預覽操作流程。*

## v2.4.0 重點功能與更新

### 1. 整合 Android 系統分享選單
將電子紙更新流程融入日常看圖與設計動線。在任何支援分享的 App 中點選分享即可喚出感應面板，更新完成後自動收起並返回原畫面，無需額外切換應用程式。

### 2. 自動識別螢幕尺寸與色彩規格
貼靠瞬間自動讀取電子紙硬體資訊並完成畫面比例裁切，無需手動查找型號。支援主流無電池 NFC 電子紙（含 **Santek EZ Sign** 系列及相容之智慧識別證、會議室桌牌、數位名片與行李牌）：
- **支援尺寸**：`1.54"`、`2.13"`、`2.66"` (含 HD)、`2.9"` (含 HD)、`3.0"`、`3.6"`、`3.7"`、`4.2"`
- **支援色彩**：黑白雙色、黑白紅三色、黑白紅黃四色、六色全彩 (Spectra 6)

### 3. 針對電子墨水最佳化的影像渲染
專為反射式電子紙顏料特性調校的色彩抖動演算法，透過黑、白、紅、黃四色點陣排列，自然呈現人像膚色與光影過渡，同時維持純淨底色及文字、QR Code 的邊緣清晰度。

### 4. Android 15 相容性與 NFC 供電穩定度提升
針對新款 Android 裝置最佳化底層 NFC 連續供電與分塊傳輸機制，降低傳輸中斷機率；若感應途中移開手機，重新貼靠即可原位續刷。內建繁體中文、英文、日文、韓文、德文、法文、西班牙文與簡體中文介面，隨系統語言自動切換。
